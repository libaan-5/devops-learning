# Lab: Task 1 - Set Up Linux Environment

## Objective

The goal of this lab was to verify that the Linux environment was setup.

## Commands Used

uname -a
whoami
pwd

## Output

What happened:

➜  ~ uname -a
Linux L 6.6.87.2-microsoft-standard-WSL2 #1 SMP PREEMPT_DYNAMIC Thu Jun  5 18:30:46 UTC 2025 x86_64 x86_64 x86_64 GNU/Linux
➜  ~ whoami
libaa
➜  ~ pwd
/home/libaa

## Challenges

- I was unfamiliar with the 'uname' command initially, [but this video explained it.](https://www.youtube.com/watch?v=ZiOeSsk6zi4)

## What I Learned

- 'uname' is used to display system information such as the kernel (Linux) and hardware.
- 'uname -a' displays all system information (available to uname).
- 'whoami' displays what user is signed in.
- 'pwd' stands for print working directory, it displays what directory is currently open.
